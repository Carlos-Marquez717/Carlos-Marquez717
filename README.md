<h2 align="center">🚀 Proyectos Destacados</h2>

### 🎫 [SupportDesk Lite API](https://github.com/Carlos-Marquez717/supportdesk-lite)
> API backend para la gestión integral de tickets de soporte técnico con cálculo de SLA, auditoría y dashboard operacional.
- **Tecnologías:** `Java`, `Spring Boot`, `PostgreSQL`, `SQLite`, `Docker`
- **Impacto:** Centralización de tickets operativos, trazabilidad mediante eventos de auditoría y automatización de métricas de servicio.

### 📦 [SOFTCON](https://github.com/Carlos-Marquez717/SOFTCONT)
> Sistema de registro y control de insumos y herramientas para bodegas de mantenimiento industrial.
- **Tecnologías:** `Python`, `Django`, `PostgreSQL`, `Bootstrap`, `Material UI`
- **Impacto:** Digitalización de procesos físicos, control preciso de inventario y trazabilidad rápida mediante códigos QR.

### 🏢 SISGAM - Sistema de Gestión Administrativa
> Plataforma administrativa integral para departamentos de mantención industrial.
- **Tecnologías:** `ASP.NET Core`, `React`, `PostgreSQL`, `Material UI`
- **Impacto:** Digitalización del 100% de los flujos de trabajo internos y generación de reportes operativos centralizados.

### 💳 [PresstApp - Sistema Contable](https://github.com/Carlos-Marquez717/prestamos)
> Solución web para la gestión de cobros, pagos recurrentes y estados financieros.
- **Tecnologías:** `PHP`, `Laravel`, `PostgreSQL`, `Tailwind CSS`
- **Impacto:** Automatización de reportes contables y reducción significativa en tiempos de cálculo y conciliación.
